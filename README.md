# DataScience

A day-by-day learning log for Python and data science, following the [30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python) challenge format. Each `NN_Day_*` folder contains the notes and code for that day.

## Getting Started

### 1. Install VS Code

Download and install VS Code from: https://code.visualstudio.com/download?_exp_download=fb315fc982

Once installed, it should look like this:

![VS Code](img/vscode_page.png)

### 2. Clone this repo

```shell
git clone git@github.com:luchenghuai/DataScience.git
```

### 3. Run the code

```shell
python 01_Day_Introduction/helloworld.py
```
