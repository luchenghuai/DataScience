# 《分寸》Dreamina Omni Reference 制作包

本目录包含 32 个 Dreamina/Seedance Omni Reference 视频提示词和全部本地参考图。每镜按列出的顺序上传图片；提示词中的 Image 1、Image 2 等对应此顺序。

## 使用规则

- 模式：`AI Video → Omni reference`。
- 每个镜头只上传该镜“References to upload”列出的图片，不要一次上传整个目录。
- `Image 1` 是构图/调度参考，`Image 2` 是 KTV 场景与连续性参考，其余是该镜可见角色肖像。
- Omni Reference 不等于首帧锁定；如需镜头间无缝衔接，从镜头 002 起应改用上一镜成片最后一帧作为 First Frame。
- 故事板图含文字时，只作视觉参考；提示词已要求忽略文字，精确字幕请后期添加。
- 推荐 16:9、1080p、24fps、低或中低运动强度。
